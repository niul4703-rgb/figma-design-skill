# 视觉与素材分析

新视觉稿、新风格或缺素材时读取，局部修改仅读涉及部分。

## 输入与视觉提炼

识别截图、原始设计、原型和需求各自提供的信息，明确目标平台、参考边界、画板尺寸和缩放。多稿找共同视觉语言，保留业务差异；视觉稿未展示的状态、交互、截断内容视为未知。

分析布局、阅读与操作顺序、固定区／滚动区；提取颜色、文字层级、间距、控件尺寸、圆角、边框、投影；识别导航、筛选、标题、卡片、表格、分页等重复模式。

参数标记明确／估计／建议，不把截图测量误差或生成图瑕疵固化为规范。已有设计系统先查匹配项；名称相同不代表规范一致。只询问影响当前决策且不能由上下文确定的问题。

## 素材清单与制作选择

仅列本任务必要素材：用途、来源、显示尺寸、背景／裁切要求、使用位置、制作方式、确认状态。

| 情况 | 处理 |
|---|---|
| 有合适独立原图 | 优先复用，核对版本、分辨率和来源许可线索 |
| 清楚的简单轮廓、线性／面性图标、几何图形 | 原生矢量或SVG，统一线宽、圆角和视觉重量 |
| 立体、玻璃质感、复杂光影或纹理 | 矢量效果不足时生成独立PNG，不反复粗糙描线 |
| 照片、插画、背景 | 原始位图或允许生成的素材，按显示场景选择构图 |
| 必须准确的Logo、真实文档、同一身份人物 | 取得原始资产，生成结果不得冒充原件 |

区分素材不适合SVG和单纯的导入错误：前者更换制作方式，后者修复技术问题。禁止切割整页截图充当最终控件资产；截图可作锁定参考或审查局部。独立照片可按构图裁切。

## PNG生成闭环

有可用且获准的生成工具时读取对应技能并执行，不将本可由工具完成的工作转交用户。遵守用户预算和来源限制；工具不可用时仅暂停依赖素材的部分，明确缺项，继续独立工作。

生成说明应包含用途、参考、主体、构图、色彩、视角、光源、材质、尺寸、透明背景及排除的文字／UI。先验证代表素材，再沿用同一视觉条件扩展系列；不要独立自由生成导致风格漂移。

按实际用途选择分辨率，通常高于显示尺寸，但不把2倍定为硬规则。验证真实alpha、边缘、主体占比、清晰度、色偏和背景适配；白底不等于透明。实际放入页面后检查图文关系和视觉重量。

达不到关键效果时迭代或说明限制，未接受的替代不能悄悄通过。PNG只用于适合位图的素材，界面文字、控件与表格仍保持原生可编辑。

素材保留有意义文件名、来源／生成依据、采用版本和使用位置；替换后同步关联实例，避免堆积无关资产。
