# 配套Figma连接器

仅在用户选择本仓库自有连接器时读取；通用skill也兼容其他有相应能力的工具。

## 查找与安装

开源仓库：https://github.com/niul4703-rgb/figma-design-skill 。仓库的“连接器”目录包含执行器.js、面板.html、manifest.json、桥接服务.py、发送指令.py；安装与连接、接口与排错在“文档”目录。个人skill目录通常不含这些程序：先查用户提供的仓库路径，不猜固定磁盘或端口。

若尚未安装，按仓库安装文档引导用户导入开发插件并启动Python服务；不要宣称仅安装skill即可操作Figma。当前为开发预览版，新认证流程需先在独立测试文件联调。

## 执行约定

1. 确认桥接运行在本机17658或17659，插件面板已手动连接。口令通过环境变量FIGMA_BRIDGE_TOKEN提供，不在聊天、URL、日志或提交文件中回显。
2. 运行发送指令.py --clients取得本次目标id和pageId；核对文件和用户指定范围。
3. 请求包含target、batch.expectedPageId、batch.operations。先capabilities与page只读，再核对实际节点ID。未连接或页面不匹配时停止写入。
4. 操作以执行器能力为准：支持基本原生节点、组件、SVG/位图、现有变量绑定、文字样式和PNG导出；不支持创建变量集合、原型连线或任意JS执行。能力不足明确说明，不伪装完成。
5. 重复key会报错，主组件及关键目标优先核实id:节点ID。每批不超过200项，实际使用小批。
6. HTTP200仍需检查每项ok；部分失败不能整批重跑。202／客户端退出码2表示运行中，用--status命令ID查询；504且cancelled才表示未领取取消。网络超时／重启后404不证明未执行。
7. 用--output保存大结果和PNG base64；导出后实际查看。tree有数量截断，大页面分区读取。
8. 状态最多128项、15分钟且仅内存保存；必要记录由项目保存，不保存口令。关闭连接不会回滚既有修改。

只修改用户授权范围；桥接token不是画板范围授权。不要将服务暴露到公网。未安装可用连接器时继续分析工作，但不声称已经写入Figma。
