# 接口与排错

## HTTP协议

所有数据接口都要求 `Authorization: Bearer <会话口令>`。服务仅绑定127.0.0.1，支持17658／17659。口令不放URL，不写入仓库。OPTIONS用于浏览器预检，不读取数据。最大请求32MiB，最大200项操作。各批次不是事务，失败后不自动回滚。

| 路径 | 用途 |
|---|---|
| GET /health | 认证后的版本检查 |
| GET /clients | 最近60秒轮询过的目标ID及页面ID |
| GET /poll?client=…&page=… | 插件领取明确指定给自己的指令；无指令为204 |
| POST /command?timeout=30 | 提交 `{target,batch:{expectedPageId,operations}}`；等待0—180秒 |
| GET /commands/命令ID | 查询 queued/running/done/cancelled 及已返回结果 |
| POST /result | 插件回传 `{id,client,result}`；重复回传不会再次执行 |

插件也检查expectedPageId，防止领取后切换页面时误写。目标ID区分插件运行实例，不能复用过期ID。它不是用户身份认证；连接口令代表对该本地会话的访问能力。

## 已实现操作

- 读取：capabilities、page、pages、inspect、tree、fonts、styles、variables。
- 节点：upsert、update、delete、clone、instance、reorder、select。
- 素材：image（base64位图）、SVG类型upsert、export（PNG）。
- 组件／样式：textStyle、bindStyle、bindVariable、combineVariants、componentProperty、setProperties。
- 页面：gotoPage、createPage。切页后重新发现目标，不把切页与后续读写放同一批。

支持原生FRAME、TEXT、RECTANGLE、ELLIPSE、LINE、VECTOR、COMPONENT和SVG导入。该执行器不提供任意JavaScript执行，不支持创建变量集合／变量、创建效果样式、SECTION或原型交互连线；variables只列出现有变量，bindVariable绑定现有变量。不要根据Figma完整API推断本工具也支持。

节点可用 `id:实际节点ID` 或自定义key定位；重复key会拒绝解析，改用核实后的ID。clone/instance需要新的唯一key。属性白名单以 `连接器/执行器.js` 的PROPS为准。

`tree` 的deep模式每父节点最多400个子节点；浅层key最多120个，page列表最多200个。较大设计需要分区读取，不能将截断结果当作完整清单。inspect中的过大样式可能被省略。

## 返回结果与状态

HTTP完成不代表每项操作成功。读取 `result.ok`、`failed` 和 `results[*].ok/error`。一批中的操作独立尝试，失败项之前甚至本项早期步骤可能已写入；先读取现状再只修剩余步骤。

发送客户端退出码：0=请求成功且批次未报告失败；1=连接／协议／执行失败；2=仍在运行，需查询。PNG导出较大时用 `--output` 保存，避免把base64打印到聊天。

## 常见问题

| 现象 | 检查 |
|---|---|
| 连接被拒绝 | 服务终端是否运行、端口一致、localhost是否被防火墙／本机权限拦截 |
| 401 | 插件和客户端使用的是不是本次服务的同一个口令 |
| 没有客户端 | 插件是否手动连接；检查面板日志。打开面板不等于连接 |
| expectedPageId不匹配 | 当前页已切换，重新读取clients，并核对用户授权范围 |
| 网络域被阻止 | 用本地开发方式导入manifest，端口必须在网络白名单内 |
| 字体不可用 | 确认字体与字重，必要时安装／启用；不静默换字体 |
| 实例子层无法移动 | 属性覆盖有限；用合适变体或范围内的新组件，不修改无关主组件 |
| 组件图标消失 | 检查源组件visible及父级隐藏方式，导出实际实例复核 |
| 结果回传失败 | 插件只重试回传，不重放设计操作；检查日志、命令ID及画布 |
| 服务重启后找不到命令 | 状态为内存保存；结果未知时不能根据404判断未执行 |

## 维护者验证

在仓库根目录执行：

```sh
python -X utf8 测试/桥接测试.py
node 测试/执行器测试.js
node --check 连接器/执行器.js
```

自动测试覆盖桥接认证、目标和页面校验、超时状态、重复回传、基础执行器校验及部分失败。执行器测试使用模拟Figma宿主，不能替代桌面端联调。

人工联调应在独立空白文件执行：只读发现 → 创建样板 → 确认可编辑 → 导出对照 → 停止连接。新开源版尚未完成该桌面联调，不应直接用于无备份的交付文件。
