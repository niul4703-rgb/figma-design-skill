# 安装与连接

## 需要什么

- 可以运行本地开发插件的 Figma 桌面端及有编辑权限的测试文件。
- Python 3.10 或更新版本。桥接服务与指令客户端只使用标准库，无需 pip 安装运行依赖。
- 支持读取 SKILL.md、运行本机命令或发送本机 HTTP 请求的 AI 宿主。生成 PNG 另需宿主提供图像生成能力。
- Node.js 仅用于维护者运行 JavaScript 测试，不是插件运行依赖。

这是开发插件安装包，不是 Figma Community 商店插件，也不是 MCP 服务；不需要填写 GitHub 或 Figma API token。

## 1. 下载仓库并安装 Skill

下载本仓库 ZIP 并解压，或运行：

```sh
git clone https://github.com/niul4703-rgb/figma-design-skill.git
cd figma-design-skill
```

把 `skills/figma-design` 整个目录复制到宿主技能目录。已有同名目录时先备份，再合并；个人项目经验不要覆盖。保留下载后的仓库路径，连接器代码不在个人 skill 文件夹里。

## 2. 启动桥接服务

在仓库根目录打开终端：

```sh
python 连接器/桥接服务.py
```

默认端口17658，也支持 `--port 17659`。服务仅监听127.0.0.1。启动后终端会显示随机会话口令；不要截图公开或提交到仓库。保持该终端运行，退出按 Ctrl+C。

需要固定口令时，可以先设置 `FIGMA_BRIDGE_TOKEN` 环境变量；至少24个无空白ASCII字符。使用随机长口令，不要把它写进仓库文件。未设置时每次启动都会生成新口令。

## 3. 在 Figma 中导入插件

打开专门用于联调的文件，通过 **Plugins → Development → Import plugin from manifest…** 选择仓库 `连接器/manifest.json`，然后从 Development 菜单运行插件。

仓库的 manifest 是本地开发配置。如果客户端要求分配插件ID，先在 Figma 创建一个开发插件，保留 Figma 分配的ID，将其填入本地 manifest 后再导入；不要把仓库占位ID当作商店发布ID。

插件只允许访问localhost的17658和17659端口。选择与终端一致的端口，粘贴会话口令并点击“连接”。成功轮询后会显示目标ID和当前页面ID。每次插件重新打开会生成新的目标ID，以防同名文件领取错误指令。

官方参考：[创建开发插件](https://help.figma.com/hc/en-us/articles/360042786733-Create-a-plugin-for-development)、[Manifest](https://developers.figma.com/docs/plugins/manifest/)、[网络访问](https://developers.figma.com/docs/plugins/making-network-requests/)。菜单或本机网络权限可能因客户端版本而不同。

## 4. 先只读检查

在另一个终端设置同一个口令。PowerShell：

```powershell
$env:FIGMA_BRIDGE_TOKEN = Read-Host '粘贴桥接口令'
python 连接器/发送指令.py --clients
```

macOS/Linux：

```sh
read -s FIGMA_BRIDGE_TOKEN
export FIGMA_BRIDGE_TOKEN
python3 连接器/发送指令.py --clients
```

将返回的 `id` 和 `pageId` 填到 `示例/只读检查.json` 的 `target`、`batch.expectedPageId`，然后运行：

```sh
python 连接器/发送指令.py --file 示例/只读检查.json
```

确认文件／页面正确再写入。若使用17659，在每次客户端调用加 `--port 17659`。告诉AI仓库所在路径与端口即可，口令由环境变量读取，不需要粘贴到聊天记录。

## 5. 测试可编辑图层与导出

仅在空白测试文件中，将相同目标信息填到 `示例/创建样板.json`：

```sh
python 连接器/发送指令.py --file 示例/创建样板.json --output 样板结果.json
```

此例创建一个卡片Frame、可编辑标题并导出PNG。输出中的 `result.results` 每项都需检查 `ok`；导出项包含base64编码的 `png`，可用Python标准库解码保存。不要把图像结果文件提交到仓库。示例使用Inter Bold，缺字体会明确报错，不会自动替换。

这只是连接测试，不是还原质量证明；正式设计仍需按skill完成视觉分析、组件确认及实际导出对照。

## 6. 超时处理与关闭

- 返回202／客户端退出码2：已被插件领取且仍在执行，使用 `--status 命令ID` 查询，不重新发送原批次。
- 返回504且 `state=cancelled`：在等待时间内未领取，已取消；核对连接后可重新发送。
- 客户端自身网络超时且没有命令ID：结果未知，先检查插件日志和画布，不直接重放。
- 插件“停止”只停止领取新任务，不撤销已执行或正在执行的修改。重启服务会丢失内存状态，先确认在途指令。
- 当前状态最多保存128项、15分钟；这是短时恢复窗口，不是持久任务数据库。复杂任务拆为小批并及时保存结果。

完成后停止插件、关闭桥接服务。要使用其他兼容连接工具，可跳过上述配套连接器，仍可使用通用skill。
